# Open Source Release Checklist

Use this checklist before pushing the project to a public repository.

- [ ] Run `rg -n "AMAP_KEY=.*[a-f0-9]{20}|securityJsCode: \\"[a-f0-9]{20}" .` and confirm no real API credentials are present.
- [ ] Confirm `.env`, `.env.local` and generated AMap HTML files are not staged.
- [ ] Confirm `outputs/amap_map/海淀小学高德互动地图.html` is regenerated locally by users and not committed with credentials.
- [ ] Confirm cached pages under `outputs/ranking_data/*.html` and `outputs/school_district/html/` are not staged.
- [ ] Confirm downloaded admission images and OCR intermediate files are not staged.
- [ ] Review `NOTICE.md` and `docs/DATA_SOURCES.md` for third-party data caveats.
- [ ] Decide whether generated Excel files should be included in the release artifacts or generated by users.
- [ ] Run `python3 -m py_compile scripts/*.py`.
- [ ] Run `zsh -n outputs/amap_map/打开高德地图.command`.
- [ ] Build the AMap page locally with your own credentials before screenshot verification.
